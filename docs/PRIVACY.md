# 本地数据与网络请求

- 无用户注册、账户体系、统计追踪或广告SDK。
- 收藏、已读、置顶等仅在当前浏览器localStorage保存，不由后台上传；清除浏览器站点数据可清除这些记录。
- 本地配置：server/config.json；抓取缓存、精选历史与设置：server/data/。不进入发布包。
- RSS/行情请求由后台发送给配置的公开来源；提供方可看到运行机器的IP及请求信息。
- 页面翻译需用户主动选择；固定界面词典本机处理，动态可见文本经后台发送给MyMemory或管理员指定的LibreTranslate。输入内容、来源配置表单、收藏视图及其侧栏副本、个人关键词说明和代码区跳过。用户自定义来源默认标为本地私有；相关标题、事件与存档跳过外部翻译，订阅名称保留原样。默认翻译不启用。
- 翻译结果仅保存在内存中，重启清除；服务仅记录HTTP路径状态，不写翻译请求正文。第三方提供方按自己的条款处理查询。
- 页面翻译不会修改原文链接、创建外站标签页或发送完整网页HTML。超过长度或不支持的文字保留原文。

此说明描述当前实现，不是对第三方服务行为的保证。公开托管前需要补充实际部署方和隐私联系方式。

作者主动公开的署名“雨花石子记”和测试域名ITIF.CN会随源码包发布。旧开发脚本、本机路径、运行日志和抓取存档不属于发布内容，原工程目录也不应整体上传。
