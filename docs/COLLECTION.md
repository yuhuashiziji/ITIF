# 公开网页采集

RSS、公开接口继续使用原来的适配器。新增 Scrapling 0.5.1 Selector 作为 HTML 解析依赖，网络请求仍经过原有公开地址校验和响应大小限制，避免引入第二条绕过安全检查的网络通道。PHP 主机无需安装 Python 或 Scrapling。

初始网页适配器：央视新闻、界面新闻、新华网、第一财经。只采公开首页标题和原文链接，不采全文；页面顺序称“网页精选”，不冒充平台热度。发布时间未知时保留空值，以抓取发现时间说明。旧日期 URL、非文章链接、异域链接、重复链接及异常条数会被过滤。

每域名串行、最少两秒间隔，读取并遵守 robots.txt；无法读取或不允许时跳过。来源之间并发，来源失败独立退避并保留原始成功时间。GitHub 每半小时尝试更新，来源间隔及退避可能更长。页面结构变化导致校验失败时不发布空白或导航内容覆盖旧新闻。

微信、搜狗仍无已经验证的免费榜单入口，保留真实不可用状态，不使用其他平台新闻伪装。没有启用浏览器渲染、自动验证码、代理池、个人 Cookie、自适应猜测或正文转载。

安装：`python -m pip install -r requirements.txt`。Scrapling 使用 BSD-3-Clause，参见 https://github.com/D4Vinci/Scrapling/blob/main/LICENSE 。依赖许可证不代表新闻内容转载授权。
