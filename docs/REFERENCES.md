# 参考与致谢

本项目原创适配器与阅读界面独立编写，未复制下列项目源码；不将这些仓库的许可套用于本项目。

- [RSSHub](https://github.com/DIYgod/RSSHub)、[RSSHub Radar](https://github.com/DIYgod/RSSHub-Radar)：RSS路由与发现思路。
- [NewsNow](https://github.com/newsnext/newsnow)：来源聚合与热榜思路。
- [Miniflux](https://github.com/miniflux/v2)、[Folo](https://github.com/RSSNext/Folo)：阅读、已读与收藏思路。
- [Horizon](https://github.com/Thysrael/Horizon)：每日精选思路。
- [World Monitor](https://github.com/koala73/worldmonitor)：事件与数据状态思路。
- [科技爱好者周刊](https://github.com/ruanyf/weekly)：Markdown周刊与社区投稿思路。
- [60s](https://github.com/vikiboss/60s)：公开热榜实例。公共实例有可用性与使用限制，建议核实条款后自建。
- [MyMemory](https://mymemory.translated.net/doc/spec.php)：免费翻译查询；只使用get查询，不自动向其翻译记忆库投稿。
- [LibreTranslate](https://github.com/LibreTranslate/LibreTranslate)：用户可选独立自建翻译服务，按其许可使用。

RSS文章、平台标识与行情属于原提供方；本项目保留原文链接，不包含其授权声明或大批量内容存档。系统字体由设备提供，无外置字体包。品牌双页标记为本站绘制。设计方向参考见DESIGN.md。
